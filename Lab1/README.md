# Lab 1 Deliverables

## Deliverables

- Requirements specification
- Use case models
- Data dictionary
- UI mockups
- AI critique

## Files

The following files contain the Lab 1 deliverables:

- `Requirements.pdf` - target users, functional requirements and non-functional requirements.
- `Use Case Models.pdf` - initial use case diagram and use case descriptions.
- `Data Dictionary.pdf` - terms, attributes and relationships used by the system.
- `UI Mockup.pdf` - screen mockups for the key use cases.
- `AI Critique.pdf` - AI review of the use case diagram and requirements.
