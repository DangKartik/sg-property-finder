# Lab 4 Deliverables

## Deliverables

- Black-box testing
- White-box testing
- Test cases and execution results
- Live demo script

## Files

The following files contain the Lab 4 deliverables:

- `Lab4 Test Cases and Testing Results.pdf` - class-focused black-box EP/BVA testing for `InputValidationControl`, followed by white-box control-flow graphs, basis paths and test results for `WeightedScoringStrategy.scoreCandidates` and `RankingControl.generateRankedRecommendations`. Supplementary white-box evidence is in the appendices.
- `Reflection for 3.3.4.pdf` - combined reflections for the two coding-agent exercises: 3.3.2 (regenerating `InputValidationControl`) and 3.3.3 (codebase quality review and refactoring).
- `generate_reflection_report.py` - regenerates the 3.3.4 reflection PDF.
- `Reflection for 3.3.2.pdf` and `Reflection for 3.3.3.pdf` - the individual reflections with their prompt and output evidence.
- `SC2006 Live Demo Script .pdf` - live demonstration script.
