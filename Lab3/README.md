# Lab 3 Deliverables

## Deliverables

- Class diagram and class diagram description
- Dialog map
- System architecture
- Technology stack
- Application skeleton

## Files

The following files contain the Lab 3 deliverables:

- `Class_Diagram.jpg` - class diagram.
- `Class Diagram Description.pdf` - class responsibilities and key design issues.
- `Dialog Map.pdf` - dialog map and Excalidraw link.
- `ArchitectureDiagram.drawio` - editable system architecture diagram.
- `TechStack.pdf` - technology stack recommendation.
- `ApplicationSkeletonReport.pdf` - AI prompts and responses used to generate the skeleton.
- `AI Generated Skeleton (3.3.3).zip` - generated application skeleton.

## Application Source Code

The generated application skeleton is provided in `AI Generated Skeleton (3.3.3).zip`. The implemented application is in `SGPropertyFinder/`.
